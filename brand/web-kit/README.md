# Phonics4All · комплект для розробника сайту

Підготовлено на основі брендбука v2. Відкрийте preview.html для перегляду всіх елементів. Комплект не потребує збірки чи зовнішнього CDN.

## Склад

- assets/logos — 6 версій логотипа/знака та 2 аватари, SVG і PNG.
- assets/icons/color — 6 кольорових іконок, SVG і PNG.
- assets/icons/mono — 6 SVG з currentColor для вставки inline.
- assets/icons/sprite.svg — 6 символів для SVG use.
- assets/characters — Max, MiMi, Kami, Lulu і 3 додаткові пози Lulu; прозорі PNG та WebP у двох розмірах.
- assets/patterns — 4 нові безшовні SVG-адаптації P1, P2, P3, P5 та PNG превʼю тайлів.
- assets/decor — 6 декоративних SVG: іскра, звук, книга, вуха Lulu, хвиля, крапки.
- assets/favicons — SVG, ICO та PNG для браузера, Apple touch і manifest.
- fonts — локальні TTF Nunito Sans та Andika із SIL OFL.
- styles — CSS зі змінними, шрифтами, кнопками, картками, фонами; JSON палітри.
- docs/integration.md — приклади підключення та правила використання.
- assets-manifest.json — список файлів, розміри та контрольні суми.

## Зафіксовані рішення

Назва у тексті — Phonics4All. Затверджена графіка логотипа зберігає історичне написання Phonics4all. Не набирайте її вручну.
Lulu відповідає за читання; основний образ — з книгою. Лисеня не використовується.
Помаранчевий фон P4 і блакитний фон P6 вилучені. Помаранчевий та блакитний у логотипі, іконках і деталях залишаються.

## Статус

Логотипи та кольорові іконки — векторизовані версії затверджених концепцій. Нові SVG-патерни та декор — спрощені адаптації для вебу, не точні копії растрових композицій брендбука. Літери P3 переведені в контури й не залежать від установленого шрифту. Персонажі залишаються растровими ілюстраціями з прозорістю; WebP отримано з PNG без зміни образів. Окремі деталі Lulu між згенерованими позами можуть відрізнятися.

Шрифти включено у TTF; CSS працює без конвертації. За потреби команда може підготувати WOFF2, зберігши українські та латинські символи й ліцензії.
