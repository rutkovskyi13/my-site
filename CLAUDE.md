# Phonics4All — контекст для Claude

Перед будь-якою роботою прочитай **`docs/handoff.md`**: там усе про проєкт, брендбук, анімацію Lulu, публікацію, перевірки й наступну задачу.

Коротко:
- Користувач не програміст: українською, простою мовою, по одному кроку, з перевіркою результату.
- `landing/` — головний сайт курсу (брендбук v2, Lulu). `site/` — сайт з алфавітом (React + Vite), його треба вбудувати в кнопку «Practice».
- Брендбук: `docs/brand-v2.md` і `brand/`. Концепція методики: `docs/concept/Phonetics4All-methodology.md` (на сайті не розкривати таблицю підказок, словникові банки й алгоритми ігор).
- Перевіряй у headless Chromium (`tools/checks/`), сервер з Range: `npx --no-install http-server -p 8766 -s -c-1 .`
