# Брендбук v2 (жовтень 2026): коротко для розробки

Джерела: `brand/Phonics4All-Brandbook-v2.pdf` (28 стор.), `brand/web-kit/` (комплект розробника v1, див. його README і docs/integration.md).

## Основне
- Слоган/суть: «Авторська методика. Світ, у якому хочеться читати.» «Читаємо разом із Lulu».
- Назва в тексті: **Phonics4All**. Логотип (графіка) зберігає написання «Phonics4all», його не набираємо шрифтом, лише SVG.
- Логотип: книга + динамік + літери abc, помаранчевий напис, блакитна 4. Версії: кольорова (на кремовому), фіолетова (на світлому), світла (на темному), знак окремо, аватари.
- Мінімум: горизонтальний 280px, знак 64px. Вільне поле = половина висоти «P».
- **Лисеня більше не використовується.** Провідник у читанні — зайчиха **Lulu** (з книгою). Інші герої: Max (дослідник), MiMi (чарівниця), Kami (друг-помічник).

- У звичайному макеті достатньо одного акценту.

## Шрифти
- **Nunito Sans**: 400 пояснення, 600 інструкції/кнопки, 800 заголовки.
- **Andika**: навчальні літери й слова (зрозумілі «a», «g», «I», «l»).
- Шрифти локальні (TTF у web-kit), без Google Fonts.

## Елементи
- 6 іконок навчальних дій: Слухай, Промовляй, Читай, Поєднуй, Пиши, Радій поступу (кольорові та моно-SVG).
- 4 патерни: P1 звуковий ритм, P2 відкриті книжки, P3 літери та іскри, P5 чотири герої (на фіолетовому). Текст не кладемо прямо на патерн, лише на чисту картку.
- Компоненти в CSS: `.p4a-button` (фіолетова «пігулка»), `.p4a-card` (біла, радіус 24px, м'яка тінь).
- Композиція навчальної сторінки: логотип угорі, одна головна дія, Lulu поруч із завданням, патерн на краю.

## Що це означає для поточного сайту
- Нинішні кольори (coral #FF6B4A, sky #4DB8FF, mint, lavender, жовтий) та шрифт Nunito замінюються на палітру й шрифти v2.
- logo.png (3 МБ) замінюється на logo-horizontal.svg (~30 КБ).
- Навчальні плитки й картки літер — шрифт Andika.
- На сторінки вправ додається Lulu (читає, показує літеру, вітає з успіхом).
